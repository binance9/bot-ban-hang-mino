Trang bán hàng Kênh Chat

🚀 Dùng bot bán hàng trong 3 bước

Không cần biết code. Làm theo đúng thứ tự, tổng cộng khoảng 15 phút.

✅ Không cần cài gì ✅ Miễn phí ✅ Làm sai chỉ cần sửa lại
1

Điền thông tin shop vào trang Cài đặt

Không cần sửa code — điền form, bấm Lưu là xong.

  1. Mở file caidat.html (hoặc bấm ⚙️ Cài đặt trên menu của trang bán hàng).
  2. Điền tên shop, số điện thoại → bấm ＋ Thêm món để nhập món bán (tên + giá).
  3. Thêm vài kịch bản: khách hỏi "giá" → bot trả câu gì; khách hỏi "ship" → trả câu gì.
  4. Bấm 💾 Lưu cài đặt → mở lại index.html (nhấn F5) — bot nói theo mình liền.
💡 Sửa hỏng muốn về như cũ? Bấm ↺ Khôi phục mặc định — mọi thứ về như ban đầu trong 1 giây.
2

Mở web cho khách vào

Chọn 1 trong 2 cách, cách nào cũng 2 phút:

  1. Dùng tại chỗ: nhấn đúp index.html — bot hoạt động ngay, phù hợp khi bán qua Zalo/gửi file cho quen.
  2. Muốn có đường link gửi khách: vào netlify.com/drop → kéo cả thư mục chứa web vào → nhận ngay 1 link (VD: shopcualan.netlify.app) → gửi link đó lên fanpage, bioshop. Miễn phí.
💡 Khách vào link, chat với bot, điền form "Đặt hàng ngay" — đơn hiện ngay trong Kênh Chat cho mình xử lý.
3

Bật bot trả lời trên Facebook / Zalo

Dùng AhaChat — miễn phí, tiếng Việt, kéo–thả, không cần code. Làm 1 lần cho cả Messenger và Zalo.

  1. Vào ahachat.com → đăng nhập bằng tài khoản Facebook.
  2. Bấm Kết nối trang → chọn fanpage của mình → đồng ý quyền.
  3. Vào mục dựng kịch bản (menu trái, tên dạng "Kịch bản / Trả lời tự động / Flow") → tạo kịch bản Trả lời theo từ khóa.
  4. Khách hỏi "giá / bao nhiêu" → dán câu trả lời giá. Thêm vài cặp hỏi–đáp: ship, đổi trả, đặt hàng (chép từ khối hoiDap ở Bước 1 là chuẩn nhất).
  5. Bấm Bật / Live. Nhắn thử fanpage — bot trả lời là xong 🎉
  6. Muốn thêm Zalo: trong AhaChat chọn Kết nối Zalo OA → đăng nhập Zalo → làm kịch bản y hệt.
💡 Mẹo: bot không cần trả lời hết — kết thúc mỗi câu bằng "để lại sđt để shop gọi tư vấn nha ạ". Sđt về tay là có đơn.

📋 Hằng ngày chỉ cần 2 phút

  • Mở admin.html (bấm "🖥️ Kênh Chat" trên menu).
  • Xem tab Chờ phản hồi → khách nào bot chưa xử lý được thì trả lời tay (gõ vào ô dưới cùng, Enter).
  • Đơn khách đặt qua form nằm sẵn ở kênh Website Chat, kèm tên + sđt + địa chỉ — gọi xác nhận là xuất kho.
💡 Ghi chú nội bộ (tab vàng trong khung chat) để ghi "khách này giao buổi sáng" — chỉ mình mình thấy.

🧰 Phần kỹ thuật — gấp lại, khi nào cần mới mở

Kết nối Messenger bằng API chính chủ (không qua AhaChat)
Cần một server có HTTPS. Đủ 7 bước:
  1. developers.facebook.com → Create App → loại Business.
  2. Thêm sản phẩm Messenger.
  3. Chọn fanpage → Generate Page Access Token.
  4. Chạy webhook tối giản (Node.js):
const express = require("express");
const app = express(); app.use(express.json());
const VERIFY_TOKEN = "mino-verify-2026";
const PAGE_TOKEN = "DÁN_PAGE_ACCESS_TOKEN";

app.get("/webhook", (req, res) => {
  if (req.query["hub.verify_token"] === VERIFY_TOKEN)
    return res.send(req.query["hub.challenge"]);
  res.sendStatus(403);
});
app.post("/webhook", async (req, res) => {
  for (const e of req.body.entry || [])
    for (const m of e.messaging || [])
      if (m.message?.text)
        await fetch("https://graph.facebook.com/v21.0/" +
          m.recipient.id + "/messages?access_token=" + PAGE_TOKEN, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({
            recipient: { id: m.sender.id },
            message: { text: "Dạ em là bot Mino nha anh/chị!" }
          })
        });
  res.sendStatus(200);
});
app.listen(3000);
  1. App Meta → Webhooks → dán https://ten-mien/webhook + Verify Token → đăng ký trường messages.
  2. Chuyển app sang Live (app Development chỉ bot trả lời được cho chính mình — lỗi "bot im" phổ biến nhất là quên chỗ này).
  3. Messenger miễn phí trong 24h kể từ tin cuối của khách; muốn nhắn sau đó phải dùng Message Tags theo quy định Meta.
Kết nối Zalo OA bằng API chính chủ
  1. Tạo Official Account tại oa.zalo.me.
  2. developers.zalo.me → tạo Ứng dụng → thêm sản phẩm Zalo OA → ghi lại OA ID, App ID, App Secret.
  3. Lấy OA Access Token theo luồng xác thực v4 (token ngắn hạn, có refresh_token — cần cron gia hạn trên server).
  4. Đăng ký Webhook HTTPS, bật sự kiện user_send_text, user_send_image.
  5. Nhận tin → trả lời qua API:
await fetch("https://openapi.zalo.me/v3.0/oa/message/cs", {
  method: "POST",
  headers: { "Content-Type": "application/json", access_token: OA_ACCESS_TOKEN },
  body: JSON.stringify({
    recipient: { user_id: USER_ID },
    message: { text: "Dạ em là bot Mino nha anh/chị!" }
  })
});

Nhớ: OA thường giới hạn số tin/tháng theo gói; tin mẫu sau bán dùng ZNS (nội dung phải được Zalo duyệt).

Khi nào cần thuê/host server riêng?
  • Muốn nhiều người cùng xem Kênh Chat từ nhiều máy khác nhau.
  • Muốn hội thoại + đơn không mất khi đổi máy/khách hàng xóa trình duyệt (hiện dữ liệu lưu trong trình duyệt — nhấn F12 → Application → Local Storage xem, xóa khoá donhang là reset).
  • Muốn bot thông minh hơn bảng từ khóa (cắm AI vào hàm botTraLoi — chỉ thay 1 hàm).
Đủ một VPS nhỏ (300–500k/tháng) hoặc Vercel/Railway gói free là chạy được webhook mục trên.

🙋 Hỏi nhanh — đáp gọn

Bot không trả lời?
Câu hỏi có chứa tên món chưa? Chưa thì bot trả lời nhờ chủ shop — đó là hành vi đúng, không phải lỗi.
Cài đặt sai, muốn về mặc định?
Mở caidat.html → bấm ↺ Khôi phục mặc định. Không bao giờ sợ hỏng file.
Đơn hàng xem ở đâu?
Mở admin.html — đơn hiện là 1 hội thoại trong kênh Website Chat, kèm giá trị đơn.
Đổi tên/màu thương hiệu?
Tên: khối CAU_HINH (Bước 1). Màu: sửa dòng --xanh và --tim ngay đầu file index/admin.
Có tốn phí gì không?
Web + bot trang web: không. AhaChat: có gói miễn phí. Messenger/Zalo gửi tin bình thường: miễn phí trong hạn mức.
